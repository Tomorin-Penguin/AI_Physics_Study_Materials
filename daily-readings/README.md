## 归档约定

- `tex/` 保存 LaTeX 源文件及其必要的附图、参考文献文件，`pdf/` 保存对应 PDF。
- 同一份材料的 `.tex` 与 `.pdf` 使用相同的文件名主体，格式为 `YYYY-MM-DD_topic`；日期为当天阅读材料的日期。
- 新增材料时更新本导览中相应年份的表格，概括材料实际覆盖的知识点；首页只保留分区导览入口。
- LaTeX 编译产生的临时文件不归档。
